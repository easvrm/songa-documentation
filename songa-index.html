About the platform

🌍 Songa Mobility Platform

Songa is an end-to-end solution for electric trike fleet management, battery energy logistics, agricultural session tracking, and multi-tenant operations across Africa.

  • Multi-tenant fleet and battery management
  • Aggregation trip planning and real-time tracking
  • Agri-tech session management (tilling, milling, pumping)
  • USSD gateway integration for low-connectivity access
  • Power Africa asset management
  • Hub-level energy KPIs and prediction

📚 Documentation overview

All five guides are self-contained single-page applications with sidebar navigation and full-text search. They are designed for offline use — no internet connection required.

  • Platform Docs — web app features and workflows
  • Admin Tools — tenant setup and access control
  • Onboarding — client getting-started guide
  • API Reference — 22 REST modules, Phase 9
  • Mobile Docs — driver and operator mobile guide
